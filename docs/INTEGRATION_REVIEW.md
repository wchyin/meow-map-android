# 模块设计与开发分工

## 业务模块

| 模块 | 内容 |
| --- | --- |
| 地图分享 | 地图浏览、定位、发布、照片、编辑删除、关键词和日期查询 |
| 观察手记 | 发现时间、地点、数量、猫咪名称、毛色特征；个人查询与维护 |
| 交流 | 地图记录点赞、取消点赞、评论、删除本人评论 |
| 账号 | 注册登录、个人资料、会话与权限 |
| 本地数据 | Room持久化、草稿、照片文件管理、查询缓存 |
| 服务器 | 统一API、数据库、图片存储、认证与业务权限 |
| 管理端 | 用户、公开记录和评论管理，数据统计 |

观察手记按账号隔离；地图分享面向所有用户。两端遵循统一数据接口，各自设计页面布局。

## 三人分工

| 成员 | 主要负责内容 | 交付要求 |
| --- | --- | --- |
| 一 | Android地图、设备能力与交流 | 地图、定位、图片选择、分享发布、详情、点赞评论 |
| 二 | Android账号、手记与数据层，桌面接口接入 | 手记管理、个人中心、Room、Repository、缓存、共享接口调用 |
| 三 | 服务器与Web管理端 | 认证、数据库、图片存储、业务接口、管理页面、统计与部署 |

共同完成需求确认、接口联调、功能测试、项目报告、运行截图和演示视频。

## 接口与存储

统一协议位于 `docs/API_CONTRACT.md`，接口示例位于 `protocol/v1/examples.json`。

Android采用 UI → ViewModel → Repository → Room / API。桌面页面通过IPC访问主进程，由主进程调用API。共享数据包括用户、地图分享、个人手记、图片、点赞与评论。

地图分享和个人手记使用独立资源；记录归属由账号确定。跨端使用字符串ID、UTC时间和WGS84坐标。数据库管理升级，覆盖安装保留已有数据。

## 当前实现与待完成项

Android的本机账号、地图分享、观察手记、互动、草稿和Room存储已经实现。服务器接口及跨设备共享待接入。

桌面提供本地JSON与Supabase数据源。共享REST数据源、会话管理、图片上传、分页和编辑冲突处理待完成。地图模块需要验证两端落点一致。

桌面运行配置还需完善preload与IPC隔离、导航控制及安装后的数据目录。服务端部署后需要验证权限、上传失败处理和实际跨端读写。
