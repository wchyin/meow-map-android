# Android 0.8.0 共享猫咪档案

## 使用

1. 新增或编辑地图打卡／普通观察，点击“关联猫咪”。
2. 输入猫咪名字或完整 ID，搜索全站已有档案；列表显示名字、ID、品种和特征，可继续加载下一页。
3. 选择同一只猫并保存观察。服务器会把已关联的猫咪自动加入该用户的 `/cats` 列表，不复制档案。
4. 确认搜索结果都不是目标猫咪时，可新建并选中，再保存观察。

档案详情显示完整 ID。创建者可维护基础资料；记录其他人建立的猫咪后可查看其共享资料及本人的相遇时间线，无编辑／删除入口。私人备注不从别人的共享档案读取。

## 协议与兼容

复用现有线上服务 `/cats/search?q=…&offset=N`，支持分页与错误重试。共享 ID 是 `创建者ID~猫咪ID`；保存观察时原样传入 `cat_id`，不截掉创建者。服务端验证关联是否存在，并按观察关系返回本人的猫咪列表。

`/cats` 返回 `is_mine` 指明创建者权限；搜索结果本身不意味着收藏或建档，保存观察后才建立记录关系。同名不会自动合并，旧的重复实体不会擅自重写。

同一共享猫咪的不同用户打卡合并为一条地图轨迹；旧数据中只有本地 ID 的猫咪仍按作者隔离，避免误合并。

备份仅导出本人创建的猫咪基础档案，观察中保留共享引用；导入本人猫咪时重映射原创建者引用，避免把共享档案复制为本人的新猫咪。

## 验证

匿名实测线上公开地图 47 条记录，其 47 个猫咪引用均已采用共享 ID，确认已有服务器协议可用。此请求未登录、未更改线上记录。

49 项单元测试通过，含共享资料隐私、创建者权限、跨用户轨迹分组、不同身份不合并以及新建后选择 ID 的测试。debug APK 构建与 Android Lint 通过。普通观察选择猫咪后，会补填原本空白的名称字段。

仍需在手机用两个账号验收：A 创建猫咪；B 按名字／完整 ID 搜索并保存观察；B 的档案出现同一 ID；B 无修改资料入口。未声称已执行线上双账号写入或手机验收。
