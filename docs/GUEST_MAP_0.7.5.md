# 0.7.5 游客地图修复及验证

## 修改

- 地图点位数据独立于头像加载发布，首次渲染不等待图片请求。
- 上传头像每完成一张便更新地图；头像加载 effect 不再依赖每次组合创建的函数引用。
- 退出登录后重新获取公开列表，避免仅恢复过期的游客缓存。
- 在发起退出请求前清除搜索、本人和日期筛选；退出请求失败也不会留下“只看本人”导致游客列表为空。

## 已执行

- 匿名请求线上 `/map_records` 与 `/observations`，各返回 46 条记录；地图记录均有对应公开观察元数据。
- 匿名读取三个不同的上传头像地址，均返回 HTTP 200 / image/jpeg，响应分别为 47214、43359、76714 字节。
- 42 项 JVM 单元测试通过，含正常退出和退出请求失败时的筛选回归测试。
- debug APK 和 Android 设备测试 APK 编译成功，Android Lint 通过。

## 设备测试

新增 GuestMapTest：慢头像下载期间点位仍可用、重组不重启下载、完成后头像进入样式；匿名 API 返回的记录与头像全部进入地图源。
隔离模拟器显示已连接，但系统启动检查和 APK 安装长时间无响应，未完成设备执行。测试编译成功不等于设备测试通过。

## 范围

接口实测是当次线上快照，不证明用户所在网络可访问，也不能替代手机上当前筛选条件及地图缩放范围的验收。公开数据仅限服务端公开接口提供的记录。
