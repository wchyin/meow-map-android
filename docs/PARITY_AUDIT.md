# 原版一致性核查

核查日期为 2026-11-19，安卓版本为 0.7.1。对照目录为 D:/Desktop/other/meow-meow。以下基于两端源码和已有构建验证，真机端到端交互需要另行核验。

## 本轮修复

| 项目 | 发现 | 修复 |
| --- | --- | --- |
| 放大底图 | 原版高德端点在校园采样点 19、20 级返回 179 字节空白 PNG，17、18 级返回正常地图。安卓瓦片声明到 19 级，地图还能继续放大 | 瓦片最大级别及地图最大放大级别均设为 18，发现、详情、编辑共用 |
| 统计页缩放 | WebView 沿用默认允许缩放，页面只指定初始比例 | 关闭手势和内置缩放控件，文本比例 100%，viewport 固定比例 |
| 地图列表单击 | 安卓打开详情，原版单击定位并高亮 | 单击返回地图、定位高亮，提供查看详情按钮，重复点击可重新定位 |
| 毛色和特征 | 原版普通观察使用 gender，安卓只读取 appearance/notes | 优先读取 gender，保留旧字段回退，保存同时写入兼容字段 |

## 已对照的共享功能

- 主导航具备地图、公开观察、我的记录、档案、统计、小助手、个人资料，手机使用底部导航和更多菜单。
- 云端认证、打卡、普通观察、档案、图片、评论和点赞使用同一套原版服务。云端和本机身份仍分离。
- 地图使用同一高德中文瓦片。Android 保存 WGS84，渲染时转 GCJ-02，点选时逆转换。
- 统计复用原版 computeStats、activityAnalytics 和十张图表代码，使用云端原始字段。展示选择栏为用户要求增加。
- 导入导出支持便携 ZIP 及兼容 JSON，原版电脑绝对图片路径需要先转换。
- 档案时间线、公开打卡及助手引用具备地图定位入口。

## 尚未完全匹配

| 范围 | 原版 | 安卓现状 |
| --- | --- | --- |
| 观察列表 | 表格列、字段排序、更细粒度的字段搜索、性别/特征和校园选择 | 原生记录行，搜索字段较少，缺少同等的列排序和普通观察校园编辑 |
| 地图聚合 | 50 米范围内按位置聚合，列表可展开簇成员 | MapLibre 屏幕像素聚合，点击放大。固定米数和列表聚合交互尚未对齐 |
| 地图头像 | 内置头像及本人自选照片 | 地图标记使用内置头像，自选头像在档案中显示，地图仍回退内置头像 |
| 轨迹与时间线时间 | 地图原版 parseRecordTime 优先 created_at，其次 time | 轨迹部分优先公开观察 time，档案时间线使用地图创建时间，含双时间字段时可能有差异 |
| 地图筛选 | 原版包含多种附近距离和高校/校区组合选项 | 安卓提供部分距离及逐校区选择，选项集合尚未逐项复刻 |
| 统计示例生成 | “添加校园示例”写入记录及档案 | 本地统计页提供展示和筛选，尚未提供该写入入口 |
| 网络异常 | 原版有底图失败提示，网络恢复效果依服务响应 | 高级别空白已修复，弱网及瞬断仍需真机核验，当前缺少同等瓦片失败提示 |

本次没有将以上未完成项标记为已一致。桌面窗口布局、系统相册/相机、触控与鼠标操作的形态差异需结合安卓平台分别验收。
