# 喵喵数据地图 · Android

校园猫地图记录与交流应用。用 Android Studio 打开本目录即可开始开发。

当前开发版本：**0.7.5**，分支 `main`。

0.7.5 将地图标注更新与头像下载解耦，避免慢头像阻塞整张地图；退出登录后重新同步公开数据，并清除搜索、本人和日期筛选。

0.7.4 修复公开猫咪上传头像被过滤、游客无法加载头像的问题；选择猫咪头像后可预览并调整缩放及位置，确认后保存为统一的正方形图片。

0.7.0 复用桌面原版统计图表和计算函数，补齐十张可视化。统计页的「展示内容」可按主题或单张图表筛选，保留统计范围和示例记录开关。

0.6.0 按桌面原版的浅青色界面重排导航，独立展示发现地图、公开观察、我的观察记录、猫咪档案、统计面板、寻猫小助手和个人档案。地图支持按猫咪档案回顾轨迹，公开观察、档案时间线和寻猫引用可定位并高亮打卡。

0.5.0 对齐桌面原版的公开观察、校园汇总与附近半径、档案头像和个人资料、数据分析及寻猫小助手。普通观察与地图打卡的公开范围遵循原版云端服务。小助手依赖服务端配置；相机拍照上传继续由原有地图编辑器提供。

0.4.0 默认适配原版桌面喵喵地图的云端服务，新增猫咪档案、记录关联、校园范围与筛选、附近排序、聚合、热力图和包含照片的 ZIP 备份。当前接口、坐标转换、兼容限制和验收范围见 [原版迁移说明](docs/ORIGINAL_MIGRATION.md)。以下原有功能说明与 0.3.0 验证记录仍保留；“仅本机”的说明适用于 `-PmeowLocal=true` 本机数据源，不能视为新云端版本的验收结果。

## 运行

- JDK 17 或 21。
- Android SDK 35，设备最低 Android 8.0（API 26）。
- Windows：`./gradlew.bat assembleDebug`。
- macOS / Linux：`sh ./gradlew assembleDebug`。
- APK：`app/build/outputs/apk/debug/app-debug.apk`。
- 本机 SDK 路径写在不提交的 `local.properties` 中，换电脑后由 Android Studio 重新生成。云端调试版可从同一文件读取 `meow.demo.email` 与 `meow.demo.password`，在登录表单预填。登录由用户点击提交，已登录的设备继续使用原会话。带预填密码的调试 APK 仅供本机测试，发布版的登录表单使用空白初始值。

## 当前可体验的功能

- 原生地图、点击标记查看记录、地图与列表浏览。
- 关键词搜索、日期范围筛选、只看我的。
- 本机账号注册、登录、退出和修改昵称。
- 地图选点、系统定位、拍照、相册多选。
- 记录新增、编辑和删除；照片压缩后复制到应用私有目录。
- 右上角「存草稿」保存未完成内容；重新打开相同编辑页可恢复，按账号隔离。
- 发布后自动清除对应草稿；删除记录、移除照片时清理无引用的私有图片。
- 地图记录点赞、取消点赞、评论和删除自己的评论。
- 本人和公开地图的记录概览、趋势、时段、来源、品种和地点分布。
- Room 持久化，应用重启后保留数据；账号密码加盐派生存储。
- 显示选中的日期范围，可一键清除所有筛选；图片读取失败时显示占位提示。
- 数据初始化或读取失败时展示错误和重新加载入口。
- 独立的个人观察手记：发现时间、地点、数量、猫咪名称与毛色特征；按账号隔离，支持新增、编辑、删除、关键词/日期筛选和累计观察数量。

本机模式首次运行包含三条明确标注的示例记录，默认地图中心是广州大学城校园附近。它们用于展示交互，不代表真实猫咪观察。注册自己的本机账号后可发布记录，也可以点赞和评论示例记录。

## 数据与地图

默认构建使用与桌面端共用的云端 Repository。地图打卡对应 `/map_records`，本人的观察记录对应 `/records`，公开观察对应 `/observations`。使用 `-PmeowLocal=true` 构建可访问原有 Room 本机数据。卸载应用会删除该设备上的本机数据。当前协议与旧版本兼容说明见 [原版迁移说明](docs/ORIGINAL_MIGRATION.md)。

原生地图由 MapLibre Android SDK 渲染，使用与桌面原版相同的高德中文底图瓦片。地图展示使用 GCJ-02 坐标，手机定位、Room 记录及校园源边界仍使用 WGS84。底图依赖网络，已有记录可通过缓存查看。

## 代码结构

```text
app/src/main/java/cn/edu/meowmap/
  MainActivity.kt           Android 入口
  MeowApplication.kt        数据库与 Repository 装配
  data/
    Database.kt            Room Entity、DAO、数据库及查询投影
    MeowRepository.kt      Repository 契约与本机实现
    MediaStore.kt          图片复制、缩放及方向处理
    PasswordHasher.kt      本机账号密码派生
  ui/
    MeowViewModel.kt        状态流、查询筛选及操作处理
    MeowApp.kt              主导航、地图、列表、账号与统计
    CampusMap.kt            原生地图及生命周期、系统定位
    EditorScreen.kt         发布编辑、相册与相机
    DetailScreen.kt         详情、点赞、评论与删除
    Theme.kt               配色与基础组件
```

UI → ViewModel → Repository → Room。Room 导出的数据库结构位于 `app/schemas/`，后续修改数据库时需要新增迁移，保留已有数据。

本地数据库版本为 4，包含用户、地图记录、照片、点赞、评论、草稿和观察手记。Room管理数据库升级，覆盖安装时保留已有数据。

## 验证

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
# 构建后，在开发电脑检查 Room 生成的迁移 SQL：
python scripts/check_migration.py
# 启动模拟器或连接 Android 手机后：
.\gradlew.bat connectedDebugAndroidTest
```

单元测试覆盖组合筛选、日期边界、密码校验；设备测试覆盖 Room 数据增删改查、点赞、评论级联删除、账号所有权隔离及发布交流流程。

0.2.0 增加了草稿照片序列化、私有图片清理范围、初始化重试与操作防重入等单元测试。新增设备测试覆盖草稿恢复、账号隔离、照片共享引用和版本升级。各版本实际执行结果见 `docs/VALIDATION.md`。

默认采用单工作线程、2 GiB Gradle JVM 堆上限和非驻留构建进程；模拟器仅在需要设备测试时手动启动。

项目功能规划与三人分工见 `ANDROID_PROJECT_BRIEF.md`。
